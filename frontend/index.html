Infrastructure Automation & Self-Healing Pipeline

1. Provisioning (Terraform)

Automates AWS VPC (10.0.0.0/16), public subnets, least-privilege security groups, and EC2 instances.

2. Configuration (Ansible)

Deploys Python virtualenv, systemd units, Gunicorn, Nginx reverse proxy, and Nagios Core 4.x.

3. Monitoring (Nagios Core)

Continuously tests HTTP /healthz and NRPE metrics. Distinguishes transient SOFT vs persistent HARD states.

4. Self-Healing (Closed-Loop)

Upon HARD CRITICAL, event handler executes Ansible recovery playbook over private VPC network to restore service.
